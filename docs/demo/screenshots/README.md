# Demo Screenshots

This folder is for local demo evidence screenshots.

Screenshots may contain local test data. Do not commit screenshots that contain real parent phone numbers, secrets, or production personal data.

## Recommended naming convention

- `01-admin-bookings-list.png`
- `02-booking-detail.png`
- `03-ai-follow-up-card.png`
- `04-follow-ups-dashboard.png`
- `05-n8n-manual-workflow.png`
- `06-n8n-manual-success.png`
- `07-n8n-daily-digest.png`
- `08-supabase-follow-up-tasks.png`
- `09-supabase-notification-bridge.png`
- `10-build-success.png`

## Screenshot privacy rules

- Blur phone numbers if real.
- Never show service role key.
- Never show automation secret.
- Never show Supabase API keys.
- Prefer sanitized demo data over real parent data.
