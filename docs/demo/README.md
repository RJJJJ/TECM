# TECM AI Operations Demo Package

TECM 是一個面向澳門教育中心的 parent-facing iOS app + Admin Web + Supabase backend + n8n-ready AI operations system。這套 demo package 用於展示、驗收、重現與交付目前已完成的 booking、staff operations、AI follow-up 與安全自動化流程。

## Demo scope

- Parent booking
- Admin booking management
- AI follow-up suggestions
- Manual WeChat / WhatsApp follow-up
- Parent notification after booking confirmed
- n8n manual workflow
- n8n daily digest

## What this demo proves

- Full-stack app structure
- Supabase data model
- Admin operations workflow
- AI-assisted staff follow-up
- Safe automation design
- No unsafe WeChat auto-send
- Human-in-the-loop AI workflow
